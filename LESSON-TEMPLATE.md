# Lesson Authoring Template

Use this shape for future lessons. Do not create empty future lesson folders.

## README.md

```markdown
# NN - Short title

## Mission

One visible Minecraft result.

## New Idea

One programming idea in practical words.

## Design First

Information:

Representation:

Example:

Prediction:

## Exercise NN.1 - Tiny Change

Change only the marked line or method.

## Play Check

Run `runClient`, open the lab world, and use the command or item.

## Refactor Check

Compare one piece of working code to a cleaner Java version.

## Checkpoint

Save a Git commit with the lesson result.
```

## Rule

Each lesson should add one visible mechanic and one named concept. If the concept needs a paragraph before the game works, the lesson is too large.
